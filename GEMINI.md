# GEMINI.md

## Project Overview

This is a website for the Frontier Dental Clinic, a dental care provider in Kisaasi, Uganda. The project is built using Next.js, React, and TypeScript, and was initially generated using [v0.app](https://v0.app). It is deployed on Netlify.

The application follows a single-page application (SPA) architecture within the Next.js framework. The main application logic resides in `src/App.tsx`, which manages page content dynamically, rather than using the standard Next.js file-system-based routing.

### Key Technologies

*   **Framework:** Next.js
*   **Language:** TypeScript
*   **UI Library:** React
*   **Styling:** Tailwind CSS
*   **Build Tool:** Vite and Next.js
*   **Linting:** ESLint
*   **Formatting:** Prettier
*   **Deployment:** Netlify

## Building and Running

### 1. Install Dependencies

The project uses `pnpm` for package management, as indicated by the `pnpm-lock.yaml` file.

```bash
pnpm install
```

### 2. Run the Development Server

The project can be run in development mode using Vite.

```bash
pnpm dev
```

This will start the development server, typically at `http://localhost:5173`.

### 3. Build for Production

To build the project for production on Netlify, use the following command:

```bash
pnpm build
```

The output of the build will be in the `.next` directory, which should be configured as the "Publish directory" in your Netlify settings.

## Development Conventions

### Coding Style

*   The project uses a strict TypeScript configuration, enforcing strong typing.
*   ESLint is used for linting, with rules for React hooks and React Refresh. The `@typescript-eslint/no-unused-vars` rule is currently disabled.
*   The codebase is formatted using Prettier.

### File Structure

*   The main application entry point is `app/page.tsx`, which renders the `src/App.tsx` component.
*   The core application logic is contained within the `src` directory.
*   The `app` directory is primarily used for the Next.js routing and layout shell.
*   Reusable UI components are located in the `components` directory, with many being generated by v0.app.
*   Page components are located in the `src/pages` directory.
*   The project uses path aliases, with `@/*` pointing to `src/*`.
